# Brand guide

All artwork is generated by code. Do not hand-edit files in `assets/`.
Regenerate them instead:

```bash
python scripts/make_brand_assets.py              # all SVGs + social PNG + preview GIF
python scripts/make_brand_assets.py --svg-only   # standard library only
```

Optional tools: `resvg-py` renders `social-preview.png`; `playwright` with
Chrome, Edge or `playwright install chromium` renders `pipeline-preview.gif`.
`tests/test_brand_assets.py` fails if a committed SVG is out of date, is not
well-formed XML, exceeds its size budget, or uses an animation that has no
`@keyframes`.

## The mark

The mark combines fingerprint ridges with camera-viewfinder corners. The ridges
are concentric, rotated ellipse arcs with gaps that act as ridge endings. The
viewfinder stands for "from image". One generator draws the ridges for the
logo, the hero's fingertip crop and the social-card background, so all three
show the same print.

| Asset | Size | Use |
|---|---:|---|
| `assets/logo.svg` | 4.6 kB | Default mark at 48 px and above |
| `assets/logo-small.svg` | 2.1 kB | Favicons and avatars at 16–40 px: 3 thick ridges and heavier corners |
| `assets/wordmark-light.svg` / `-dark.svg` | 5.0 kB | README header lockup, used with `<picture>` |
| `assets/logo-animated.svg` | 28.7 kB | Animated mark, 7.2 s loop |
| `assets/pipeline-animated.svg` / `-light.svg` | 110 kB | Hero animation, 8 s loop, dark and light cards |
| `assets/pipeline-preview.gif` | 0.46 MB | GIF of the hero for places that do not run SVG animation (social posts, slides, PyPI) |
| `assets/social-preview.svg` / `.png` | 36 kB / 194 kB | GitHub social preview, 1280 × 640 |

At 32 px, `logo.svg` turns into moiré because its 8 ridges are about 1 px apart.
Use `logo-small.svg` for anything 40 px or smaller.

## Palette

| Token | Hex | Role |
|---|---|---|
| Teal | `#14B8A6` | Gradient start, primary brand colour |
| Teal light | `#2DD4BF` | Accents on dark backgrounds, progress, match highlight |
| Teal dark | `#0D9488` | Accent text on light backgrounds (contrast ≥ 3:1) |
| Indigo | `#6366F1` | Gradient end |
| Indigo light | `#818CF8` | Negative embedding values, encoder activations |
| Amber | `#F59E0B` | Detections only: minutiae markers. Never used for decoration |
| Ink | `#0F172A` | Text on light backgrounds |
| Paper | `#F8FAFC` | Text on dark backgrounds |
| Slate 400 / 600 | `#94A3B8` / `#475569` | Muted text (dark / light) |
| Card dark | `#0B1120` → `#111B30` | Hero card and social-card background |

The brand gradient runs diagonally from teal (top-left) to indigo
(bottom-right). Embedding cells use a diverging scale: indigo for negative
values, a neutral surface colour near zero, and teal for positive values.

## Typography

No web fonts. GitHub serves SVGs through `<img>`, which blocks external
resources, so every asset uses system font stacks:

- **Sans** (titles, prose): `ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`
- **Mono** (labels, identifiers, scores): `ui-monospace, SFMono-Regular, 'SF Mono', Menlo, Consolas, 'Liberation Mono', monospace`

Use the mono stack for anything that is data: finger labels, `right_index`,
cosine scores, step numbers. In the hero, text is at least 12 units on a
960-unit canvas, which is at least 10 px at the README width of 800 px.

## Motion

- **One master clock.** Every animation in a file has the same duration and
  runs `infinite`. Keyframe times are absolute seconds converted to
  percentages, which keeps all elements in phase and the loop seamless. See
  `Timeline` in `scripts/make_brand_core.py`.
- **The static styling is the final frame.** Animations only override that
  styling. With `prefers-reduced-motion: reduce`, or in a renderer without CSS
  animation, the file shows the finished state: the complete pipeline for the
  hero, and the clean mark for the logo.
- **CSS keyframes only.** No JavaScript, no SMIL, no external resources, so the
  files animate inside GitHub's `<img>` sandbox.
- **Motion must carry information.** Minutiae appear when the scan beam
  reaches them. Gallery rows brighten while they are compared. Scores count up
  to the real cosine of the bars on screen (a test checks this).
- **Easing:** `cubic-bezier(.22,1,.36,1)` for entrances,
  `cubic-bezier(.34,1.56,.64,1)` for lock-on overshoot, and
  `cubic-bezier(.65,0,.35,1)` for fades and loop resets.

### Hero storyboard (8 s)

| t (s) | Beat |
|---|---|
| 0.1–0.75 | Hand silhouette rises in |
| 0.6–1.6 | 21 landmarks pop in (MediaPipe topology) and the skeleton draws |
| 1.45–2.3 | Five oriented fingertip boxes lock on with labels; the index box is selected |
| 2.2–3.35 | Zoom into an upright index crop; a scan sweeps it from raw to enhanced, detecting 9 minutiae |
| 2.95–4.5 | Features stream into the encoder, layers light up, and a 32-cell unit embedding condenses |
| 4.45–6.2 | Each gallery row is compared and its score counts up; `alice · right_index` wins with **MATCH 0.94** and the other rows dim |
| 7.5–7.9 | Fade to the empty state, then loop |

### Animated mark (7.2 s)

The ridges draw on from the inside out. A scan beam then sweeps down, and each
minutia marker flashes as the beam passes it. The viewfinder corners lock
inward with an overshoot and the mark bounces slightly. After that the mark
idles with a breathing glow, then fades out and the loop restarts.

## Usage rules

- Keep clear space around the mark of at least ¼ of its width. Do not place it
  on busy imagery.
- Do not recolour, rotate or stretch the mark, and do not add effects. On
  photos, use it on a solid Ink or Paper plate.
- Teal light (`#2DD4BF`) is for dark backgrounds only. Use teal dark
  (`#0D9488`) for accent text on white.
- Amber means "something was detected". Keep it for minutiae and similar
  detections.
- Use the dark hero card on dark pages and the light card on light pages. The
  README snippet below switches between them automatically.
- For any place that does not run SVG animation, use `pipeline-preview.gif`.
  Do not screenshot the SVG.

## README snippet

Paste this below the badges, in place of the current animated-logo block:

```html
<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/pipeline-animated.svg">
    <img src="assets/pipeline-animated-light.svg" width="800"
         alt="Pipeline: a hand photo gets 21 learned landmarks and five upright fingertip crops; the index crop is enhanced, embedded as a unit vector, and matched against an enrolled gallery by cosine similarity (MATCH 0.94).">
  </picture>
</p>
```

To keep the small animated mark next to the header:

```html
<img src="assets/logo-animated.svg" alt="Animated fingerprint scan" width="120">
```

Social preview: in the GitHub repository go to **Settings → General → Social
preview** and upload `assets/social-preview.png`. For a favicon, for example
on a docs site, use `assets/logo-small.svg`.
