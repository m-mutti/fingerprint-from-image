# Fingerprint training data

Status: 2026-10-22. Data lives in the git-ignored `data/` directory of the main checkout
(`E:\Personal_tries\Mutti_Finger_Prints\data`); nothing under `data/` is committed.

**FVC2004 (DB1-4, sets A and B) is the held-out test set.** The manifest builder tags every
FVC2004 row `split: heldout`. If a training image duplicates an FVC2004 image, the training
copy is excluded. Never train on `heldout`.

## 2. Manifest format

`data/manifests/<slug>.jsonl` (FVC sets are grouped as `FVC2000.jsonl`, `FVC2002.jsonl`,
`FVC2004.jsonl`), plus `all.jsonl` and `SUMMARY.md`. There is one JSON object per image.
The schema is in `src/fingerprint_from_image/data/schema.py`:

`path` (absolute), `dataset`, `subject`, `finger` (`right_index` ... / `unknown` /
dataset-local `finger_<n>`), `identity` = `<dataset>:<subject>:<finger>` (the class label),
`impression`, `sensor`, `modality` (`contact_optical | contact_capacitive | contact_thermal |
contact_unknown | rolled | latent | contactless | synthetic`), `dpi`, `dpi_source`, `width`,
`height`, `split` (`train | val | test | heldout`), `license`, `sha256`, `mode`, `synthetic`,
`variant` (`""` for originals; e.g. `altered:CR:Easy`, `distorted`), `duplicate_group`,
`exclude`, `exclude_reason`, and `attributes` (e.g. `ridge_period_px`, `angle`,
`appearance`, `capture`, `set`).

**Always drop `exclude: true` rows.** `ManifestDataset` does this by default.

## 3. Quality control applied

* Every file is decoded with Pillow. Undecodable, constant or tiny files are dropped and
  listed in `SUMMARY.md` and `quality_report.json`. 16-bit, colour and LA images are
  flagged and converted to 8-bit grey by the loader.
* Exact duplicates (SHA-256) and near duplicates are found across **all** datasets.
  Candidates come from masked high-pass 64x64 descriptors (whole frame + ridge crop),
  then are verified at 160-192 px (threshold 0.6). The copy in the most protected split is
  kept (heldout > test > val > train); the others get `exclude: true` and a
  `duplicate_group`. Altered variants of an excluded print are excluded too.
* Subject-disjoint splits with a fixed seed (0); `check_splits` verifies that no identity,
  subject, duplicate group or image hash spans two splits and that FVC2004 is `heldout`
  only. The build fails if any check fails.
* `dpi_source = estimate:...` means the dpi was derived from the median ridge period,
  calibrated on 500-dpi FVC sensors (about 9.2 px per ridge at 500 dpi).

## 4. Rebuild

```bash
uv venv .venv -p 3.12 && uv pip install -p .venv -e ".[dev]" gdown
# download (resumable, verified, safe extraction; research-only sets need the flag)
python scripts/download_datasets.py --data-root ../../data --socofing --accept-socofing-license
python scripts/download_datasets.py --data-root ../../data --no-fvc --extra all --accept-research-terms
# synthetic identities (about 1 h on 6 CPU workers)
python -m fingerprint_from_image.data.synth.generate --out ../../data/synth_procedural \
    --identities 5000 --impressions 8 --seed 0 --workers 6
# manifests + SUMMARY.md + quality_report.json (probe cache makes reruns fast)
python -m fingerprint_from_image.data.build --data-root ../../data --workers 8
```

## 6. Needs the user (nothing below was submitted on your behalf)

1. **NIST SD302** (highest value: contact devices + contactless + raw phone photos 302f):
   fill in https://nigos.nist.gov/datasets/sd302/request. A time-limited link is emailed.
   Optionally do the same for SD300 (`/sd300/request`) and SD301 (`/sd301/request`). The
   terms prohibit redistribution and require deletion on request.
2. **PolyU contactless 2D <-> contact 2D v1** and **3D v2**: submit the forms at
   `www4.comp.polyu.edu.hk/~csajaykr/database_request/ContactlessFP/` and `.../3DfingerprintV2/`.
3. **IIITD ISPFDv2 / ISPFDv1 / UNFIT / MOLF**: download the licence PDF from
   https://iab-rubric.org/resources/biometric-datasets/fingerprint. Have an institutional
   signatory sign it, then email it to databases@iab-rubric.org with the subject line the
   page gives. The password for the public Drive zip comes back by email.
4. **RidgeBase**: sign
   https://cubs.buffalo.edu/docs/UB-RidgeBase-database-release-agreement-08152022.pdf and
   email it to cubs-ridgebase@buffalo.edu.
5. **CASIA-V5**: register at www.idealtest.org and request dataset 7.
6. **FVC2006**: send the licence, signed by permanent faculty, to atvs@uam.es with the
   subject "[DATABASE download: FVC2006]". **LivDet**: email livdet@gmail.com.
7. After receiving any of these, add an indexer in `data/indexers*.py` and rebuild.
