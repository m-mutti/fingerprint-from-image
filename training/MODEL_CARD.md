# Model card — `fingerprint_embedder_v1`

_Status: draft; metrics are filled from `training/EXPERIMENTS.md` once the release model is
selected._

## Summary

Fixed-length fingerprint embedding (256-d, L2-normalised) for verification and
identification by cosine similarity. ConvNeXt-V2-Tiny backbone (ImageNet-22k FCMAE
pre-training, 1-channel stem), concat(avg, max) pooling → LayerNorm → Linear → BatchNorm,
trained with an ArcFace margin loss over finger identities. Runtime:
`fingerprint_from_image.embedding.FingerprintEmbedder` (numpy + Pillow + onnxruntime).

## Intended use

* Research and non-commercial prototyping of fingerprint verification/identification on
  cropped fingerprint images (contact sensors, scanned prints, fingertip crops).
* Not for law-enforcement, border-control or other high-stakes decisions without
  independent, population-specific evaluation and calibrated thresholds.
* Not a liveness / presentation-attack detector.

## Input contract

Any grayscale or RGB fingerprint image. Preprocessing
(`embedding/preprocess.py`, identical in training, evaluation and runtime): trim uniform
frame bars → Welch ridge-period estimate → resample to 6 px per ridge → 256×256 crop around
the foreground centroid → masked z-score (clip ±3, background → 0). Model input
`(N, 1, 256, 256)` float32; output `(N, 256)` unit-norm float32.

## Limitations

* SOCOFing provides one real impression per finger; impression-to-impression variation
  is learned from augmentation, 40 FVC2000 fingers and synthetic prints. Real
  multi-impression training data is the main missing ingredient.
* Ridge-period normalisation can fail on very low-quality or tiny partial prints
  (sub-harmonic picks were observed on 2 / 80 FVC2004 DB2 images).
* No minutiae-level interpretability; scores are not calibrated probabilities.
* Demographic performance differences have not been measured.
